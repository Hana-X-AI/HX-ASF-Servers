Model

TARGET-STATE; verified working on 2026-08-13.

  • Router HX-Router at 192.168.50.1 runs dnsmasq as the local resolver.
  • Domain: hx.local.arpa. Clients must use 192.168.50.1 as DNS for these names.
  • Persistent records live in /jffs/hx-hosts on the router. The loader /jffs/hx-dns-load.sh replaces the HX-managed block in /etc/hosts and reloads dnsmasq. /etc/hosts itself is regenerated by stock ASUSWRT and is not persistent.
  • Naming: hxs-N.hx.local.arpa for fleet servers; hxs-cp.hx.local.arpa for the control plane. Never hx-N.
  • Allocation: 192.168.50.200–215 in use (hxs-1 through hxs-15 plus hxs-cp). First free address: 192.168.50.216. [OPEN CORRECTION 2026-08-29, labeled, append-only: the allocation table is stale. Router reboot behavior

/jffs survives a reboot, but automatic execution of the loader after reboot is not proven on this firmware. After any router restart:

/jffs/hx-dns-load.sh
nslookup hxs-1.hx.local.arpa 192.168.50.1   # verify
